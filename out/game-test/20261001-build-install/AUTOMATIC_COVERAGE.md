# รองรับภารกิจอัตโนมัติ — 2026-10-01

เปลี่ยนจากรายชื่อด่านที่แปลแล้วเป็นกฎ `[0-9][0-9]_*` และ `P_[0-9][0-9]_*` แบบไม่สนตัวพิมพ์ใหญ่เล็ก ไฟล์ภารกิจทั้ง **38 ไฟล์** รวม co-op และ P_ ใช้ UTF-16/PUA ตั้งแต่ตอนนี้ เติม `th` แล้วบิลด์ทั้งข้อความและฟอนต์ได้เลย ไม่ต้องเพิ่มชื่อด่านใน config หรือเล่นไปถึงด่านนั้นเพื่อตรวจ encoding/glyph coverage ซ้ำ

## สิ่งที่ตรวจอัตโนมัติก่อนแพ็ก

`build.py --umd --install` เรียกตัวตรวจหลังคอมไพล์และสร้างฟอนต์ ก่อน repack/install:

- ตรวจไฟล์/section/key ที่ควรคอมไพล์ เทียบค่าที่ serialize จริงกับคำแปลหรืออังกฤษ fallback รวมค่าที่ตั้งใจคง template ว่างไว้
- ตรวจ BOM และค่า PUA ของข้อความให้ตรงกับ catalog ปัจจุบัน ข้อความไทยที่ยังไม่ shape ในไฟล์ Magma จะไม่ผ่าน
- ตรวจ PUA lookup ครบทุก cluster ในฟอนต์ทั้งหกขนาด
- ไฟล์ขาด ข้อความเปลี่ยน glyph ขาด หรือ atlas overflow จะหยุดบิลด์ก่อนติดตั้ง

รอบนี้ผ่าน **52 ไฟล์ / 8,537 ค่า / 529 PUA clusters / 6 Magma fonts** มี automated regression **34 tests** รวมการจำลองเติมคำแปล Bank ใน workspace ชั่วคราวแล้วตรวจคอมไพล์/ฟอนต์ทุกขนาด และการจงใจทำไฟล์ BOM, glyph lookup และข้อความ shaping เสียเพื่อยืนยันว่าตัวตรวจปฏิเสธได้

คำแปลจริงและ `data/raw_official` ไม่มีการแก้ไข

## การใช้งานหลังแปลเพิ่ม

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\.venv\Scripts\python.exe build.py --umd --install
```

ปิดเกมก่อนติดตั้ง ไม่ต้องแก้รายชื่อด่าน และต้องบิลด์ข้อความกับฟอนต์พร้อมกันเสมอ เพราะคำแปลใหม่อาจเปลี่ยน mapping ของ PUA

## ขอบเขตที่ยังต้องตรวจด้วยภาพ

ระบบนี้ขยายการรองรับ **ไฟล์ภารกิจ** และตรวจความครบถ้วนของผลคอมไพล์ทุกไฟล์ ไม่ได้พิสูจน์ renderer ทุกแบบจากผลบิลด์อย่างเดียว ไฟล์ engine/legacy ที่ใช้ PCX ยังใช้เส้นทาง CP874 เดิมตาม config

ตรวจตัวแทนของชนิดหน้าจอที่ยังไม่มีหลักฐาน เช่น dialogue subtitles และเส้นทาง PCX ที่ต่างจาก Magma เพียงพอสำหรับยืนยัน renderer ร่วมกัน ไม่จำเป็นต้องเล่นทุกภารกิจเพื่อตรวจว่า glyph/encoding ถูกแพ็กหรือไม่ หลังยืนยัน renderer แล้ว การตรวจตามบริบทและข้อความล้นช่องยังเป็นงาน QA ของคำแปล โดยเฉพาะชื่อ SC-20K ที่ยาวเกิน HUD ตามภาพเดิม

Atlas มีขนาด 1024×1024 และ PUA catalog มีขอบเขตจำกัด หากคำแปลใหม่ใช้พื้นที่เกินความจุ บิลด์จะรายงาน overflow ให้แก้ที่ตัวสร้างฟอนต์ก่อนติดตั้ง การตรวจอัตโนมัติป้องกันการปล่อยผลลัพธ์ที่รู้ว่าขาด glyph แต่ไม่รับรองว่าคำแปลจำนวนเท่าใดก็จะพอดีโดยไม่ต้องขยาย atlas

ไม่มีการเล่นครบทุกภารกิจหรือพิสูจน์ save/load และ co-op runtime เพิ่มในรอบนี้
