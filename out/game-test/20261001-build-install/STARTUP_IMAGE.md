# ติดตั้งภาพเปิดเกมภาษาไทย — 2026-10-01

ติดตั้งภาพที่ผู้ใช้ทำไว้จาก `dist/System/splintercell3logo.bmp` และ `SplinterCell3Logo.tga` ไปยังโฟลเดอร์ System ของเกมแล้ว เพิ่มการคัดลอกภาพเหล่านี้ในตัวติดตั้ง เพื่อให้การติดตั้งครั้งต่อไปทำงานนี้อัตโนมัติด้วย

ภาพ BMP มีขนาด 640×480 และเป็น indexed palette เช่นเดียวกับต้นฉบับ ส่วน TGA เป็น RGB 640×480 ตรวจว่าไฟล์ทั้งคู่เปิดอ่านได้และ SHA-256 ที่ติดตั้งตรงกับไฟล์ผู้ใช้ทุกไบต์

ภาพ BMP เดิมถูกสำรองไว้ที่ `backups/System/splintercell3logo.bmp` และตรวจ hash ตรงกับไฟล์ก่อนติดตั้ง ต้นฉบับเกมไม่มีไฟล์ TGA ชื่อนี้

- [ข้อมูลก่อนติดตั้งและ hash ภาพ](startup-preinstall.json)
- [ผลตรวจไฟล์ติดตั้ง 73 ไฟล์](startup-integrity.json): ผ่าน; UMD และ executable hash ไม่เปลี่ยนจากฉบับอัตโนมัติ
- [ภาพเกมหลังเปิด](21-game-after-startup-image-install.png): เปิดถึงหน้าจอเกมได้ที่ 1600×900, version 1.05 ภาพนี้แสดงหน้าเครดิต ไม่ใช่หลักฐานจับภาพ splash ภาษาไทย ซึ่งปรากฏช่วงสั้นและจับไม่ทัน
