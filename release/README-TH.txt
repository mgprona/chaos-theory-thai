สิ่งที่ต้องมี
- เกม Splinter Cell Chaos Theory PC/Steam ของผู้เล่นเอง รุ่น 1.05
  แพ็กนี้ตรวจไฟล์ของ Steam build 252084 รองรับเฉพาะ hash ที่ระบุใน manifest.json
- Windows และ Windows PowerShell 5.1 ซึ่งมีมากับ Windows รุ่นปัจจุบัน
- พื้นที่ว่างอย่างน้อย 2 GB ในไดรฟ์เกม สำหรับไฟล์ชั่วคราวและการสำรอง
- ตั้งภาษาเกมเป็น English (int) และปิดเกมก่อนติดตั้ง/ถอนม็อด
- ไม่ต้องติดตั้ง Python ฟอนต์ หรือไลบรารีสำหรับ build

วิธีติดตั้ง
1. แตก ZIP ทั้งหมดลงโฟลเดอร์ใหม่ก่อน ห้ามเปิดตัวติดตั้งจากภายใน ZIP
2. ถ้าใช้ม็อดภาษาอื่นหรือเคยติดตั้งฉบับพัฒนา ให้คืนไฟล์เกมต้นฉบับก่อน
   ตัวติดตั้งจะปฏิเสธ UMD ที่ถูกแก้ไขแล้ว เพื่อไม่ลงทับม็อดอื่น
3. ใน Steam เลือกภาษาเกม English และปิดเกม
4. เปิด Check.cmd เพื่อตรวจความเข้ากันได้โดยยังไม่แก้ไขไฟล์
5. เปิด Install.cmd ตัวติดตั้งค้นหาโฟลเดอร์ Steam อัตโนมัติ
   ถ้าหาไม่พบ ให้ระบุโฟลเดอร์เกมที่มี System และ Data อยู่ข้างใน
   ไม่ใช่โฟลเดอร์ System และไม่ใช่โฟลเดอร์ที่แตกแพ็กม็อด
6. รอข้อความ Installed และจำนวนไฟล์ที่ตรวจผ่าน แล้วเปิดเกมตามปกติ

หากต้องการระบุพาธเอง ใช้ PowerShell จากโฟลเดอร์แพ็ก:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -GameDir "D:\SteamLibrary\steamapps\common\Splintercell Chaos Theory"

ตัวติดตั้งตรวจแพ็กทั้งหมด สร้าง UMD จากไฟล์เกมเดิม ตรวจ SHA-256 ของผลลัพธ์
สำรองทุกไฟล์ที่จะทับ และตรวจไฟล์ที่ติดตั้งครบ 73 ไฟล์
ไม่แก้ executable, INI, เซฟ, โปรไฟล์ หรือไฟล์ WidescreenFix
หากติดตั้งซ้ำจะตรวจไฟล์ที่ลงไว้และแจ้งว่าติดตั้งแล้ว โดยไม่สำรองทับไฟล์เดิม

ตรวจหลังติดตั้ง
เปิด Verify.cmd เพื่อเทียบไฟล์เกมทั้ง 73 ไฟล์กับ manifest.json
การตรวจนี้พิสูจน์ความครบถ้วนของไฟล์ ไม่ใช่การตรวจการแสดงผลในเกม

วิธีถอนม็อด
ตัวถอนนี้ใช้กับการลงผ่านแพ็ก RC เท่านั้น การลงด้วย CLI ฉบับพัฒนาใช้ backup ของโปรเจกต์
1. ปิดเกม
2. เปิด Uninstall.cmd จากแพ็กเดียวกับที่ใช้ติดตั้ง
3. ตัวถอนคืนไฟล์ที่มีอยู่ก่อนติดตั้ง และลบเฉพาะไฟล์ที่ม็อดเพิ่มใหม่
   โฟลเดอร์ว่างบางส่วนอาจยังอยู่ และสำเนาต้นฉบับจะเก็บไว้ต่อ
4. ถ้าแก้ไฟล์ม็อดภายหลัง ตัวถอนจะหยุดเพื่อไม่ทับงานของคุณ
   เก็บไฟล์ที่แก้ไว้ แล้วคืนไฟล์ของแพ็กฉบับนี้ก่อนลองถอนอีกครั้ง

การสำรองอยู่ในโฟลเดอร์ .chaos-theory-thai ภายในโฟลเดอร์เกม
เก็บโฟลเดอร์นี้และ ZIP ไว้จนกว่าจะถอนม็อดสำเร็จ
หากติดตั้งถูกขัดจังหวะ ให้รัน Uninstall.cmd เพื่อคืนจากสำเนาสำรองก่อนติดตั้งใหม่
ถ้าติดตั้งล้มเหลวระหว่างคัดลอก ตัวติดตั้งจะพยายามคืนไฟล์เดิมทันที

แก้ปัญหา
- SHA-256 mismatch ของ UMD: เกมไม่ตรงฉบับที่รองรับหรือมีม็อดเดิม
  คืนต้นฉบับก่อน สามารถใช้ Verify integrity ใน Steam เพื่อคืนไฟล์เกมได้
  การตรวจของ Steam อาจทับม็อดอื่น ให้เก็บงานอื่นไว้ก่อน
- SHA-256 mismatch ของแพ็ก: แตก ZIP ใหม่ และตรวจ checksum ที่ให้มากับ ZIP
- Access denied: คลิกขวา Install.cmd/Uninstall.cmd แล้ว Run as administrator
- Windows แจ้งไฟล์จากอินเทอร์เน็ต: หลังตรวจแหล่งที่มาและ checksum แล้ว
  คลิกขวา ZIP > Properties > Unblock ก่อนแตกไฟล์ใหม่
- ภาษาเกม: System\Settings.ini ต้องมี Language=int และใน
  System\SplinterCell3.ini ส่วน [Engine.Engine] ต้องมี Language=int
  และในส่วน [Init] ต้องมี UseDynamicDataFile=true
  ตรวจว่าตั้งในส่วนที่ถูกต้องก่อนแก้ด้วยตนเอง
- ฟอนต์ผิดหรือข้อความเพี้ยน: ใช้ Verify.cmd และหลีกเลี่ยงการผสมไฟล์จากคนละบิลด์

สถานะ RC และข้อจำกัด
RC คือฉบับพร้อมให้ผู้เล่นทดลองและรายงานผลก่อนรุ่นเสถียร
บิลด์ล่าสุดผ่านการตรวจคอมไพล์ ข้อความ round-trip PUA ฟอนต์หกขนาด
ความครบถ้วนของ archive และการทดสอบติดตั้ง/ถอนในโฟลเดอร์จำลอง
ภาพทดสอบเกมจริงที่มีในโปรเจกต์เป็นของบิลด์ก่อนเกลาคำแปลล่าสุด
จึงยังไม่รับรองการแสดงผลทุกหน้าจอของแพ็กนี้
ยังไม่ได้เล่นครบทุกภารกิจ ตรวจ co-op/network หรือพิสูจน์ save/load ของแพ็กนี้
HUD ของบิลด์เก่าเคยมีชื่อ SC-20K ล้นช่อง ต้องตรวจฉบับนี้ในเกมอีกครั้ง
ข้อความที่ผู้เล่นพิมพ์ใหม่ไม่ได้ผ่านระบบ shaping ที่ใช้กับข้อความในแพ็ก
