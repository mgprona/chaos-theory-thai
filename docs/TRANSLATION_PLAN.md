## 4. ขั้นตอนต่อภารกิจ (Definition of Done)

1. **ข้อมูลแปล** — สร้าง `tools/translations_<mission>.py` เก็บ dict `TRANSLATIONS[section][key] = "ไทย"` (ตามแบบ `tools/build_02_translations.py`)
2. **ตัวเติม + ตรวจ** — `tools/build_<mission>_translations.py` ตรวจว่า key ตรงกัน 1:1 ทั้งไฟล์ (ขาด/เกิน = fail), ค่าไม่ว่าง, CP874 เขียนได้, ไม่มีอักขระต้องห้าม, ช่องว่างหัว–ท้ายตรงกับ `en` แล้วจึงเขียน JSON (`ensure_ascii=False, indent=2` + ขึ้นบรรทัดใหม่ปิดไฟล์ — รูปแบบเดิมของทุกไฟล์ ทำให้ diff แตะเฉพาะบรรทัด `"th"`)
3. **เทสต์** — เพิ่ม `test_story_<mission>_translations_complete_and_cp874` ใน `tests/test_toolchain.py` (นับสตริงตรง, CP874, อักขระต้องห้าม, whitespace mirror, canonical terms 5–15 จุด)
4. **บิลด์ + ติดตั้ง** — ปิดเกมก่อน แล้วรัน

   ```powershell
   $env:PYTHONIOENCODING = 'utf-8'
   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
   .\.venv\Scripts\python.exe build.py --umd --install
   .\.venv\Scripts\python.exe tools/validate_translations.py
   git diff --check
   ```

5. **หลักฐานในเกม** — เข้าเล่นภารกิจนั้น เก็บภาพอย่างน้อย: บทบรรยายสรุป (briefing), วัตถุประสงค์ OPSAT, บทสนทนา/ซับไทเทิล, อุปกรณ์แนะนำ แล้วบันทึกใน `out/game-test/<วันที่>/REPORT.md` (ระบุเวอร์ชันเกม, ความละเอียด, หน้าจอที่ตรวจ, ส่วนที่ยังไม่ได้ตรวจ)

## 7. ความเสี่ยง (วัดจริงแล้ว)

### 7.1 พื้นที่ฟอนต์ Magma — **ยังเหลือพอ**

PUA catalog ปัจจุบัน **529 clusters** จากข้อความไทย 3,458 สตริง และโตแบบอิ่มตัว:

| ปริมาณข้อความ | clusters |
| --- | --- |
| 864 (25%) | 424 |
| 1,729 (50%) | 496 |
| 2,593 (75%) | 509 |
| 3,458 (100%) | **529** |

ต่อให้ข้อความเพิ่มเป็น 2.2 เท่า จำนวน cluster ที่เพิ่มจะไม่เยอะ ส่วน atlas ทั้ง 6 ขนาดเหลือช่องว่างสำหรับ glyph เพิ่ม (วัดจากการ pack จริง): Bios 48 แคบสุดที่ **+535 glyph**, Prototype 36 **+848**, Prototype 26 **+2,117** — เพียงพอสำหรับงานที่เหลือ แต่ต้อง **บิลด์ข้อความและฟอนต์พร้อมกันทุกชุด** เพราะคำแปลใหม่อาจเปลี่ยน mapping ของ PUA

### 7.2 ความเสี่ยงอื่น

- **คุณภาพภาษาเป็นงานคนละชั้นกับเทสต์** — เทสต์ตรวจได้แค่ความครบ/encoding/whitespace ไม่ตรวจความถูกต้องของสำนวน ต้องมีรอบรีวิวเทียบศัพท์และโทน
- **งานซ้ำมีอยู่จริงแต่ไม่มาก** — ในกลุ่มที่ยังไม่แปลมีข้อความอังกฤษซ้ำกัน **399 ข้อความ / 1,040 สตริง** (เช่น `Alarm Stage Four - Full Alert...` ซ้ำ 20 ครั้ง, `Exfiltrate to the primary extraction point.` ซ้ำ 9 ครั้ง) แปลครั้งเดียวแล้วใช้ซ้ำได้ ประหยัดจริงราว **~640 สตริง** หรือ 13% ของงานที่เหลือ
- **ปัญหาค้างเดิม:** ชื่อ SC-20K ยาวเกินช่อง HUD — ต้องมีรอบปรับถ้อยคำ/เลย์เอาต์แยก ไม่ใช่ปัญหางานแปล
- **ยังไม่มีหลักฐานภาพ:** dialogue subtitles, รายละเอียด OPSAT, co-op/network, save/load, ความละเอียดอื่น — ต้องสุ่มเก็บภาพชนิดหน้าจอที่ยังไม่เคยตรวจ
